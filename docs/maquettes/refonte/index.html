Accent secondaire proposé pour Hubperso : « indigo brume » #93A0FF

Un seul accent, discret : marque du menu actif, point de la marque, sur-titre de page. Jamais pour un état. Plus bleu que le violet #8B5CF6 de FinanceAI (donc reconnaissable) ; contraste 7,9:1 sur les cartes, contre 4,50 pour le violet (limite), donc utilisable pour du petit texte.
